# Lenguajes de Marcas · DAM 25/26

Apuntes, ejercicios y exámenes de práctica de la asignatura **Lenguajes de Marcas y Sistemas de Gestión de Información** de 1.º de Desarrollo de Aplicaciones Multiplataforma (DAM), curso 2025/2026.

## De qué trata la asignatura

Los lenguajes de marcas son los que estructuran información con etiquetas. La asignatura recorre los más usados: **HTML** y **CSS** para construir páginas web, **XML** para representar e intercambiar datos (con su validación y transformación) y formatos como JSON, además de cómo se usan para gestionar y publicar información.

## Qué hay en el repositorio

| Carpeta | Contenido |
|---|---|
| `Apuntes/` | Teoría de la asignatura. |
| `Ejercicios/` | Ejercicios por unidad, evaluaciones de fin de unidad, trimestrales y simulacros de examen. |
| `Web/` | Páginas web hechas durante el curso con HTML y CSS. |
| `000-Plantillas/` | Plantillas base reutilizadas en los ejercicios. |

Es el material con el que estudié la asignatura y el punto de partida de todo lo que después hice en desarrollo web.
